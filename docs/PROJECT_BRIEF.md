# 프로젝트 기준 문서 v1

원본: 2026-10-19 대화에서 사용자가 전달한 mangsang.lab 계획서.

## 목적과 역할

망상 → 대화 → 가설 → 조사/창작 → 프로젝트 → Threads 공유.
ChatGPT와 사용자가 아이디어·설정 토론·원작 정합성·캐릭터 심리·장면·대사·원고를 만든다. Codex는 저장·구조화·시각화·버전 관리·검토 지원을 담당한다. 설정을 임의 변경하거나 스토리를 대신 만들지 않는다.

## 절대 원칙

1. 에드의 연금술을 되돌리지 않는다. 지식은 남아 있다.
2. 기존 인물 성격을 편의로 바꾸지 않는다.
3. CANON/INFERENCE/ORIGINAL과 확정 여부를 구분한다.
4. 진리=이슈발라 등 원작 미스터리를 함부로 확정하지 않는다.

## 기획 흐름

프롤로그: 서쪽 여행 중 광산 사고를 지식으로 해결하는 에드.
ACT1: 알의 편지 → 이슈발 → 스카 → 형 연구 흔적 → 세 문양.
ACT2: 옛 지도와 사라진 교역로 → 사막.
ACT3: 싱 → 알과 메이 → 황제가 된 링과 부족 갈등.
ACT4: 연금술/용맥/이슈발라의 숨결이 설명하는 흐름을 탐구하되 답을 성급히 확정하지 않는다.
병렬: 에드의 여정/알의 연구/링의 통치/머스탱의 개혁과 전쟁 책임.

## 질문·인물·구성 원본

실제 구조화된 목록은 `site/data/project.json`에 있다. 각 기록은 출처 `brief-v1`을 보존한다. 에드의 귀환 후 시작점과 여행 중 프롤로그의 시점, 고대 자료의 창작 분류, 유사성과 동일성 구분은 결정이 필요한 검토 항목이다. 원고는 아직 없다.

## 후속 분석 계약

원고가 생기면 원문 버전을 보존하고 사건·정보·단서·회수 근거를 연결한다. 분석 후보와 사람의 확정을 구분한다. 대사는 서술 사실로 자동 승격하지 않는다. 오류가 없다는 단정이나 근거 없는 종합 점수는 제공하지 않는다.

## Threads

원고 전문 대신 창작 중 생긴 질문과 과정을 공유한다. 댓글 반응이 설정을 자동으로 변경하지 않는다. 사용자의 사이트 주소를 글에 포함하지 않는다.

## 원고 제출 v1

프롤로그와 제1화를 사용자 메시지에서 원문 그대로 등록했다. 등록 요청에 따라 공개 읽기 화면에 포함한다. `manuscripts/000-prologue.md`, `manuscripts/001-eastbound.md`가 원본이며, 교정하지 않은 표기(예: 리스embool)도 보존한다. 프롤로그는 서쪽 여행 중, 제1화는 귀환 후 동쪽행이라는 원고의 흐름을 유지한다. 기존 계획서 검토 상태와 미스터리 상태는 자동으로 변경하지 않는다.

사용자가 원고와 함께 명시한 방향: 에드가 주인공, 알의 시점은 편지/흔적으로만 등장, 머스탱/링의 짧은 시점 전환, 스카 형의 연단술 지식에서 출발해 이슈발라 질문으로 접근. 후속 원고에도 참고하되 새 이야기를 임의로 생성하지 않는다.
