# Causal Chains

## 카이룬 체인

바이 정치 영향력
→ 안족 반대 네트워크
→ 카이룬에게 정보·자원 도달
→ 개인 과거의 해석
→ 린 암살
→ 란팡의 제압
→ 장신구 발견
→ 에드의 바이 가설
→ 조사와 가설 붕괴
→ 사회 갈등은 계속

## 루한 체인

→ 패배 수용
→ 웨이의 압박
→ 린 신뢰와 무장 해제
→ 사망과 죄책감
→ 내가 황제였다면
→ 린의 실제 보호
→ 후계자 공포
→ 개혁 문서
→ 쿠데타
