# Causal Chains

## 카이룬 체인

바이 정치 영향력
→ 안족 반대 네트워크
→ 카이룬에게 정보·자원 도달
→ 개인 과거의 해석
→ 린 암살
→ 란팡의 제압
→ 장신구 발견
→ 에드의 바이 가설
→ 조사와 가설 붕괴
→ 사회 갈등은 계속

## 루한 체인

부족을 위한 황위 교육
→ 패배 수용
→ 웨이의 압박
→ 린 신뢰와 자경단 무기 공동 봉인
→ 바이 상인 사망·원인 미확정·루한의 죄책감
→ 내가 황제였다면
→ 린의 실제 보호
→ 후계자 공포
→ 개혁 문서
→ 쿠데타

## 그라우스 체인

브래들리 경험
→ 머스탱 원한
→ 독립 조사
→ 바르크 신뢰
→ 통제 전쟁 계획
→ 바르크의 세 차례 민간인 살해·그라우스의 첫 사건부터의 인지와 묵인
→ T0 명령
→ 유기적 확전
→ 통제 상실
→ 바르크 거부
→ 재판

## 정보·명령 해석 체인

이 체인은 원고 속에서 해설하지 않는 검증용 구조다.

전달된 정보 또는 명령
→ 각자의 과거·이해관계·성격에 따른 해석
→ 행동
→ 전달자가 통제하지 못한 결과

- 카이룬은 간접 정보와 자기 경험을 결합해 독자적으로 암살을 결론낸다.
- 에드는 참인 증거들로 바이족의 암살 지시라는 오답을 만들었다가 수정한다.
- 젠하는 영향력 행사의 결과가 카이룬까지 갈 것을 통제하지 못한다.
- 그라우스는 목표를 바르크에게 전달하고, 바르크의 최적화가 실제 전쟁으로 번지는 것을 통제하지 못한다.
- 루한은 외부 기대가 피해·죄책감·두려움을 지나 자기 생각처럼 굳어진다.

카이룬 체인의 ‘란팡의 제압’은 **란팡의 살해**로 읽는다. 카이룬은 죽었으므로 자백을 통한 해결은 없다.

## 카르사 지식·에드 가설 체인 (Ch9–27)

카르사 도착·계산 불일치
→ 이름 없는 방식과 대가 질문
→ 자연의 흐름과 구조가 만든 길
→ 카르사·싱의 여행자 이전 지식 확인
→ 단일 기원 가설 폐기
→ 더 넓은 환경을 등가교환의 계로 이해
→ Ch26 옛 안족 석판으로 서쪽 여행자=반 호엔하임 확인
→ Ch25 카이룬의 한 연성진과 기존 흐름을 관찰
→ 카르사의 방식과 유사하지만 직접 계보는 확정하지 않음
→ Ch26–27 기술의 출처와 카이룬 개인을 별도로 조사

카르사는 흐름이 지나갈 길을 **만들고**, 카이룬은 이미 존재하는 흐름을 **읽는다**. 원고에서 이 체인을 도식적 주제 설명으로 반복하지 않는다.

옛 안족 영역이 카르사와 싱의 접경이었다는 지리적 배경은 지식 교류의 가능성을 설명하지만 직접 기술 계보의 증거는 아니다. 호엔하임은 옛 안족 영역을 거쳐 싱 내륙으로 갔고 스카의 형은 후대 상단망을 타고 란시로 갔다. 현대 연단술은 싱의 의학·기·용맥 지식과 동서 교류가 긴 시간 만나 발전한 결과이며, 카이룬은 그 지식을 높은 수준으로 응용한 사람 중 하나다.

## 아메스트리스 연금술–진리 체인 (작가 확정 2026-10-21, 작품 안에서는 에드의 가설)

아메스트리스의 땅 에너지가 처음부터 크세르크세스 사람들의 영혼과 얽혀 있었다 (원작 후반 설정, 재확인 필요)
→ 아메스트리스 연금술의 강한 등가교환 감각
→ 시전자 자신이 힘의 통로이자 대가가 돌아오는 자리라는 이해(땅의 힘을 쓰되)
→ 큰 힘을 얻으려면 자신을 거는 대가
→ 현자의 돌(타인을 원천으로 쓰는 발상)과 진리의 문 앞의 대가
→ 다른 지역 방식(카르사·연단술·카이룬)은 자연의 흐름에 기대 문을 거치지 않음
→ 이 체계를 가르친 호문쿨루스는 모든 것을 아는 존재가 아니었다

## 란시 충돌 체인 (Ch33)

카이룬 사건 이후 불신 → 양측 전사의 란시 유입 → 장례 중 원인 불명 화재 → 확인되지 않은 안족 방화설 → 보복 → 실제 안족 사망 → 상호 보복 → 숙련 전사·연단술사 개입 → 부족 간 무력충돌 → 린의 양측 보호 → 바이족 피해도 막지 못함 → 루한: 린은 틀리지 않았다 → 그러나 린은 바이족만 선택할 수 없다 → 내가 황제여야 하나

## 이슈발 안정화 체인 (Ch34)

머스탱 이슈발 도착 → 군-주민 충돌 접점 축소 → 이슈발 주민 대상 포격 → 머스탱의 불꽃으로 요격 → 불꽃이 살상에서 보호 수단으로 역전 → 마일즈·스카와 비학살 안정화 → 충돌 감소 → 그라우스의 전제에 균열 → 바르크가 안정 속도를 인식 → Ch36 전쟁 종료를 임무 실패로 판단 → 스카 표적화

## 란시 쿠데타 체인 (Ch35, 개정)

바이족을 지키라는 교육 → 린 신뢰와 무기 봉인 설득 → 상인 피살(인과 불명) → 안족·바이족 무력충돌 → 린의 양측 보호와 바이족 사망 → 린은 틀리지 않았다 → 그러나 바이족만 우선할 수 없다 → 그럼 바이족은 누가 먼저 지키나 → 추가 사망 → 내가 황제가 되어야 한다 / 그 수밖에 없다 → 린에게 칼을 듦 → 에드·란팡을 돌파 → 린이 직접 검을 뽑아 제압 → 루한: 모르겠습니다 → 바이족이 무기를 내려놓음 → 천루오가 안족의 보복을 막음 → 물리적 충돌 종료, 제도 문제는 남음

## 바르크 종결 체인 (Ch36)

첫 세 건의 설명되지 않는 살해 → 호크아이가 숙련 사수의 패턴을 의심 → 자신의 이슈발 경험으로 추론 → 전쟁이 식음 → 스카가 다음 표적일 것이라는 추론 → 의도적 관찰 → 스카가 노출됨 → 사수의 시선으로 감시자를 찾음 → 첨탑에서 바르크 발견 → 서로 인식, 호크아이가 먼저 쏨 → 바르크 사망 → 머스탱이 그라우스를 찾아감

## 전후 충돌 체인 (Ch37)

그라우스 구금 → 이슈발이 며칠 안정 → 브란트가 중앙에서 이슈발로 이동 → 임명 책임 인정 → 구금 소식과 미확인 소문 확산 → 전후 군중 형성 → 주민이 칼을 꺼내고 병사가 총을 듦 → 브란트가 개입 → 총성, 브란트 사망 → 단일 가해자로 규정할 수 없음 → 사람이 아니라 체제를 바꾸라는 과제

## 그라우스의 동기 체인 (Ch38)

그라우스의 여러 전쟁 경험 + 브래들리식 결단형 통치관 + 약속의 날 소외감 → 머스탱·올리비에·마일즈 부상 → 열등감과 정치적 야심 → 이슈발 전쟁을 키워 머스탱을 끌어들임 → (비학살이면 무능 / 학살이면 위선자) → 어느 쪽이든 머스탱이 약해짐 → 선호: 머스탱 실패 후 그라우스가 종료 → 실제: 머스탱이 대규모 살상 없이 안정 → 양면 모델 붕괴 → '당신은 안 그랬습니까?' → 외부 시선 인식 → 브란트의 유언 → 좋은 지도자가 아니라 군 집중 구조가 문제 → 군인이 이끌지 않는 나라

## 란팡의 비살상 체인 (Ch25→35)

카이룬이 린을 습격 → 란팡이 카이룬을 사살 → 린 '다음부터는 죽이지 마' → 루한이 린에게 접근 → 란팡이 치명적으로 끝낼 수 있는 순간에 비살상으로 전환 → 찰나의 지연 → 바이족 전사의 병사 공격을 막느라 재추격 지연 → 루한이 린에게 도달 → 린이 직접 검을 뽑아 제압 → 루한의 확신 붕괴

## 싱 제도 전환 체인 (Ch39)

황제가 권리를 결정 → 카이룬: 황제를 없앤다 → 루한: 내가 황제가 된다 → 카이룬 사망·루한 패배 → 두 답 모두 황제가 너무 중요하다는 전제 → 천루오: 다음 황제도 지킵니까? → 린이 인장을 찍지 않음 → 당사자 대표가 결정 참여 → 황실 단독 결정 범위 축소 → 미래 남부 교역로는 현재 당사자들이 선택
