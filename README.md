# Fullmetal Alchemist: East Project

강철의 연금술사 : 동쪽으로. 사용자가 만든 후속편의 설정·인물·질문·원고를 보존하는 비공식 창작 연구소.

## 접속

공개: https://yulmserver.tail261e6c.ts.net:10000/east/

로컬: `python scripts/serve.py` → http://127.0.0.1:8091

작가 전용: https://yulmserver.tail261e6c.ts.net:8444/?view=master (Tailscale 연결 필요). 공개 Funnel과 분리된 tailnet 전용 Serve다. 로컬은 `python scripts/serve.py --author` → http://127.0.0.1:8092.

## 스토리 나침반 v2.1

`private/STORY_MASTER_PLAN_v2.1.md`에 사용자 마스터 플랜 전문 23절과 Political Board 추가 지침을 보존한다. `private/master-data.json`은 구조화한 활성 기준이다. v1·v2 원문과 private/archive의 해당 JSON은 이력으로 보존한다. 확정 결정 9개는 `private/STORY_DECISIONS_v2.1.md`에 별도 보존하며 이전 미정·충돌 표현보다 우선한다. 실제 설정·독자 지식·현재 에드의 가설·공개 예정 단계를 별도 필드로 관리한다. 미래 가설과 실제 회수 완료를 혼동하지 않는다. 미정 공개 시점은 null, 5파트의 화수 범위는 fixed=false로 관리한다.

작가용 화면에는 인과관계 13단계, 성장축 6개, 5파트 로드맵, 확정 검토 처리 결과 9개와 맞는 흐름 5개를 등록했다. 공개표는 작가용 10개/독자용 6개로, 아직 나오지 않은 자원·대표권 문제는 제목부터 공개 자료에 넣지 않는다. 제1화 v3는 서부 국경지역 대표로, 제2화 v2는 사용자 승인 대화에 따라 연구 순서 확정을 가설로 교정했다. 이전 원고와 교정 전 분석은 보존한다. 광물의 합금 핵심 용도·싱 수요·운송 우위는 확정하되 명칭·수치·분석 방법은 미정이다.

`?view=politics`의 Political Board는 지도자·집단·당사자 16개를 다룬다. 원하는 것/두려워하는 것/양보선/비타협 조건/관계를 표시하고 검색·그룹 필터·관계 연결·로컬 검토 메모를 지원한다. 명시된 요구에서 양보선은 추정하지 않는다. 링의 양보선·비타협 조건은 사용자 예시로 표시한다. 협상 참여자 8집단과 의제 6개를 등록하되 대표 선정·수익 비율·집행 방식은 미정이다. 메모는 기존 작업함 내보내기에 포함되며 서버 기준을 바꾸지 않는다.

검토 결정 9개: 발견 순서 확정 / 2화 가설 교정 완료 / 에드 서→동 동선 확정 / 1화 서부 대표 교정 완료 / Al Trail 원칙 확정 / 합금 소재·싱 수요·운송 우위 확정 / 대표 선출·협정 구조 후반 설계 보류 / 중반 알 합류 폐기 완료 / 고대 문화와 자원 발견 연결 확정.

Mystery Board의 Al Trail은 실제 편지 1기록과 미집필 예시 4기록을 분리한다. 발신·수신 날짜와 도시를 소급 발명하지 않는다. 실제 설정 확정과 원고 공개·회수 완료를 구분한다. 마일즈는 전체 대표가 아닌 당사자·연결자이며, 다양한 내부 입장이 실제 협상에 참여한다. 에드는 서쪽으로 되돌아가지 않고 최종부 싱 측 구간에서 알과 재회한다.

최종 빌드는 반드시 `python scripts/build_views.py`를 실행한다. 내부에서 원고 게시 스크립트를 먼저 실행한 뒤 공개 `site/`와 작가용 `author-site/`를 생성한다. 원고 게시 스크립트만 단독 실행한 결과를 배포하지 않는다. 공개 데이터에는 마스터 플랜·결말·미공개 실제 설정·미래 가설을 넣지 않는다. 화면에서 숨기는 방식에 의존하지 않는다. 작가용 출력은 Git에서 제외하며 서버에서도 빌드한다. `private/`와 `author-site/`를 공개 정적 루트에 복사하지 않는다.

## 등록 원고

- 프롤로그 — 연금술을 못 쓰는 연금술사 / 원문 v1 / 2,748자
- 제1화 — 동쪽으로 가는 길 / 교정본 v3 / 7,184자
- 제2화 — 신의 이름 / 교정본 v2 / 10,000자

사용자가 대화로 전달하고 대시보드 등록을 요청한 원고다. 원문은 `manuscripts/*.md`에 보존한다. `python scripts/publish_manuscripts.py`로 `site/data/project.json`의 공개 등록 원고를 생성한다. 기본적으로 줄바꿈/BOM만 정규화한다. 사용자가 요청한 오타 교정은 원본을 별도 보존하고 교정 이력을 남긴다. 초기 교정은 제1화 리스embool → 리셈블이었고, v2.1 결정에서 제1화 부족 방향과 제2화 가설 표현을 추가 교정했다. 프롤로그는 원문 v1 그대로다. 본문 SHA256과 글자 수를 기록하고 원본과 일치하는지 테스트한다.

외부 주소에서 `?view=manuscripts`로 목록을, `?view=manuscripts&entry=ms-prologue-v1`과 `entry=ms-001-v1`로 각 원고를 직접 읽을 수 있다. 원문 다운로드·회차 이동·글자 크기 조절·본문 전체 검색을 지원한다. 초기 챕터 구성안의 번호는 등록 원고의 회차와 별도로 유지한다. 원고 등록을 원작 검증이나 떡밥 회수 완료로 취급하지 않는다. 제2화는 `entry=ms-002-v1`로 읽는다. 기존 문서 ID는 링크 호환을 위해 유지하며 제1화 기존 주소도 최신 교정본 v3를 보여준다.

## 보존과 공개 범위

`site/data/project.json`이 공유되는 기준 자료다. 사용자 계획서를 보존하며 원작 출처 확인이 끝나지 않은 CANON은 검증 완료로 표시하지 않는다. 미스터리의 계획된 단서와 확인된 단서를 구분한다. 원고 없는 상태에서 개연성·회수 성능 점수를 만들지 않는다.

작업함은 localStorage `mangsang-east-workspace-v1`에 저장된다. 서버 쓰기 API와 자동 동기화는 없다. 원고를 붙여넣거나 가져와도 외부 모델이나 서버에 전송하지 않는다. 다른 기기에서는 JSON으로 이동한다. 브라우저 데이터 정리/기기 분실에 대비해 내보내기를 사용한다. 서버 기준 자료로 승격할 때는 사용자 확정 내용을 별도로 검토하고 커밋한다.

공개 등록 원고는 서버 기준 자료로 모든 방문자가 읽을 수 있다. 브라우저 작업함 원고는 공유되지 않는다.

원고 전체의 의미 분석, 인물 지식 그래프 자동 추출, AI 기반 회수 판정, 실제 Threads 게시 연동은 이번 버전에 포함하지 않는다. 설정/스토리를 자동 생성하거나 원본을 임의 변경하지 않는다. Threads용 공유 시 사용자의 사이트 주소는 넣지 않는다.

## 배포

`docker compose up -d`로 Caddy가 127.0.0.1:8091에서 읽기 전용 정적 자료를 제공한다. 기존 Funnel 10000의 `/east`에만 연결하고 `/`와 `/ggolde`는 유지한다.

먼저 `python3 scripts/build_views.py`를 실행한다. 작가용 Caddy는 127.0.0.1:8092에서 별도 루트를 제공하며 `tailscale serve --bg --https=8444 http://127.0.0.1:8092`로 연결한다. 8444에 Funnel을 활성화하지 않는다. tailnet 구성원이 접근할 수 있으며 사용자별 로그인을 제공하는 구조는 아니다.

`tailscale funnel --bg --https=10000 --set-path=/east http://127.0.0.1:8091`

원작 저작권자와 제휴하거나 공식 인증받은 서비스가 아니다. 외부 분석 서비스·추적 코드·비밀키는 포함하지 않는다.

## 제2화까지의 원고 분석

`?view=analysis`는 이번 대화에서 Codex가 읽고 정리한 검토를 보여준다. 사이트에서 자동 실행되는 의미 기반 AI 분석은 아니다.

- 원작·추론·인물 지식·조사 절차·서술 시점 검토 6항목, 우선 확인 2항목.
- 원고에서 유지된 원칙과 연결 6항목, 떡밥/갈등 추적 6항목.
- 근거 카드는 해당 회차와 문단으로 연결한다. 인물의 가설을 원작 사실로 승격하지 않는다.
- 원작 만화 전권/영상 대사를 직접 전수 대조한 검증은 아니다. 공식 애니메이션 페이지와 팬 위키의 출처 수준을 구분한다. 마일즈 혈통 비율은 보조 자료에서 1/4로 확인되지만 공식 소개는 혈통 자체만 확인하므로 원작 대사 직접 대조가 남아 있다.
- 미스터리 기본 상태와 분석 의견은 별도다. 회수 완료를 자동으로 확정하지 않는다.
- 원고 분석: `docs/STORY_REVIEW.json`, 교정 이력: `docs/PROOFREADING.json`.
